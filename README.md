# Publicering och formulär
Ladda upp hela mappen till Netlify. Formuläret heter `order`.

För att få meddelanden till din e-post:
1. Öppna projektet i Netlify.
2. Gå till Forms och kontrollera att `order` finns.
3. Gå till Project configuration > Notifications > Emails and webhooks.
4. Välj Add notification > Email notification > New form submission.
5. Välj `order` och ange din e-postadress.

Byt även hej@syriangold.se och övriga företagsuppgifter före lansering.
